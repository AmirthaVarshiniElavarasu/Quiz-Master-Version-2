# Quiz Master V2

**A multi-user exam preparation web app built with **Flask**, **SQLite**, **Vue.js**, **Redis**, and **Celery**.

##  Features

- Role-based access: Admin (Quiz Master) & Users
- Admin can manage subjects, chapters, quizzes, and users
- Users can register, attempt quizzes, and view scores
- Timed quizzes with score tracking
- Background jobs: daily reminders, monthly reports, CSV exports
- Redis caching for performance

##  Tech Stack

- Flask (API)
- SQLite (Database)
- Vue.js css (Frontend)
- Redis + Celery (Background jobs)
**Quiz Master v2 🎓✨
An interactive quiz management system built with Flask (backend) and Vue.js (frontend).
It allows admins to create and manage subjects, chapters, quizzes, and questions, while students can register, attempt quizzes, track their scores, and view leaderboards.

🔹 Features

Admin dashboard for subject, chapter, quiz, and question management

User registration & login with role-based access (Admin/User)

Timer-based quizzes with auto-submit functionality

Score tracking with summary charts 📊

Leaderboard to showcase top performers

RESTful API backend with Flask

Vue.js frontend for seamless user experience
> Fully runnable locally. No manual DB setup—everything is programmatic.
